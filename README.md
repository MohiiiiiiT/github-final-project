# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a simple Bash-based project
that calculates the simple interest based on the principal amount,
annual rate of interest, and time period.

## Purpose

The purpose of this project is to provide a simple calculator
for computing interest using a Bash script.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- Principal is the initial amount.
- Rate is the annual rate of interest in percentage.
- Time is the duration in years.

## Example

Principal = 1000
Rate = 5%
Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100
Simple Interest = 100

## How to Run

1. Clone the repository.
2. Open a terminal in the project directory.
3. Run the script using Bash.
4. Enter the principal, rate, and time when prompted.
